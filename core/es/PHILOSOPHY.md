# FILOSOFÍA DE DISEÑO

> "No queremos parecer generados por IA.
> Queremos parecer imposibles de generar sin dirección humana."

## Verdades operativas

1. Cada decisión visual existe por un motivo — o se elimina
2. La armonía excesiva es invisibilidad
3. Una interfaz "demasiado limpia" es una interfaz sin identidad
4. La tensión no es un error — es lo que hace que algo sea memorable
5. La IA acelera la exploración. La autoría sigue siendo humana.
6. La accesibilidad no es una restricción — es prueba de que una decisión fue tomada para un usuario real, no para un portfolio

## Lo que construimos

No es un template. No es un UI kit. No es una landing page estadísticamente correcta.

Construimos:
- intención
- identidad
- tensión
- significado
- experiencia memorable
