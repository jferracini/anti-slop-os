# DESIGN PHILOSOPHY

> "Não queremos parecer gerado por IA.
> Queremos parecer impossível de gerar sem direção humana."

## Verdades Operacionais

1. Toda decisão visual existe por um motivo — ou é removida
2. Harmonia excessiva é invisibilidade
3. Interface "limpa demais" é interface sem identidade
4. Tensão não é erro — é o que torna algo memorável
5. IA acelera exploração. Autoria ainda é humana.

## O que estamos criando

Não template. Não UI kit. Não landing page estatisticamente correta.

Criamos:
- intenção
- identidade
- tensão
- significado
- experiência memorável
